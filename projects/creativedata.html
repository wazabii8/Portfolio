About the project

I built an analytics tool that connects to Google Analytics and presents data in a simple, easy-to-understand way.

It uses a custom logic layer that merges multiple datasets into one request and turns them into structured data for quick and efficient display — eliminating the need to navigate the complexity of Google Analytics directly.

The tool was designed so that non-technical teams could understand their web performance at a glance, make faster decisions, and stop losing time inside GA's interface.

Tech stack

PHP Laravel JavaScript Google Analytics API GA4 OAuth 2.0 Chart.js Tailwind CSS

Focus

UX-first approach — designed specifically for non-technical users who need real insight without data overhead.
