A modern SaaS platform for chemical management and risk assessments, built with a headless PHP Laravel backend and a React Single Page Application.

About the project

Mitt KemRisk is a modern SaaS platform for chemical management and risk assessments. As the primary developer responsible for the platform, I handled ongoing development, maintenance, framework upgrades, refactoring, bug fixes, and new feature delivery.

I implemented an automated SDS crawler that scans the web for updated safety data sheets and uses a locally powered LLM to validate relevance before notifying users — reducing manual work and supporting compliance.

I also developed a QR-based solution that allows laboratory staff to instantly access chemical inventories, safety data sheets, and hazard information by scanning codes placed on rooms or lockers, improving both safety and operational efficiency.

Tech stack

PHP Laravel React TypeScript SPA LLM / AI QR Integration MySQL REST API
