About the project

I created an advanced site builder from scratch based on a technique I developed, known as the Structured Editor. This method is an evolution of Dynamic DOM techniques.

It's a fun side project built on my free time, that I then tried on some Creative Army projects. The Structured Editor approach gives each component a predictable, queryable shape — making programmatic manipulation of the page tree reliable and fast.

The result is a builder that feels native and snappy, with no third-party editor dependency.
